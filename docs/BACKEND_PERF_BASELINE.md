## 4. DB-4 改写与结论（2026-11-23）

- **改写**（见 `_10K` 报告 §4 完整证据链）：`listItemsPaged` 的 `item_content` 全表加载 → 页内行
  批量取；`q` 页内 JS 过滤 → SQL 下推。1k 数据集 p50 144→118ms（-18%）——小数据集收益有限
  （悬崖在 10k：686→167ms，-76%）。
- **索引审计：零改动**。分页排序键 `(updated_at, id)` 与 `items_updated_id_idx` 匹配；其余表索引
  齐备；按 database-optimizer 纪律不建冗余索引。
- **遗留候选**：`search` 端点全表扫描 p95 752ms @10k（超 SLO）——与 P3 语义检索（GAP-14）一并裁。
- **SLO 对照（N=10k，PGlite）**：读 p95 ≤500ms → list 190ms ✅ / keyword 270ms ✅ / search 752ms ❌；
  写 p95 ≤800ms → 57ms ✅。可用性口径待 SRE-1 落地后进监控。
